# CodeAlpha_FitnessTracker

A simple fitness tracker built with React and Vite for the CodeAlpha App Development internship (Task 3).

## Features
- Log activities manually: type, date, minutes, calories burned, steps
- Dashboard with daily progress bars against goals
- 7-day bar chart for steps, calories or minutes
- Data saved in the browser (localStorage), no backend needed
- Works on phones and desktops, with dark mode

## Run it
```
npm install
npm run dev
```

## Change the daily goals
Edit the `GOALS` object at the top of `src/App.jsx`.
